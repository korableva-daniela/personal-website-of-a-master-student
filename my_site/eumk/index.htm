Анализ данных в Python

Электронный учебно-методический комплекс по дисциплине Б1.О.15 «Анализ данных в Python» для направления подготовки 01.03.02 «Прикладная математика и информатика». Комплекс содержит аннотацию курса, рабочую учебную программу, теоретический материал (4 лекции) и практические работы (4 лабораторные).

О дисциплине

Цель: изучение основных методов разведывательного анализа данных и машинного обучения с точки зрения их практического применения; формирование навыков работы с библиотеками языка Python (NumPy, Pandas, Matplotlib, Seaborn, SciPy, Scikit-learn).

Основные задачи:

  • освоить методологию анализа данных;
  • изучить инструментарий Python для работы с данными;
  • овладеть методами подготовки и разведывательного анализа данных;
  • изучить основы машинного обучения и построения моделей классификации.

Объём: 2 зачётные единицы (72 часа).

Тестирование по курсу

Тестирование по курсу

Для проверки знаний по дисциплине «Анализ данных в Python» предлагается пройти итоговый тест. Тест включает 20 заданий по всем разделам курса. Результат отображается сразу после завершения. Время прохождения тестирования ограничено: не более 40 минут.

Инструкция к тестированию

Перед началом теста убедитесь в стабильном подключении к интернету и удобном рабочем месте. Тест выполняется в одном окне — не закрывайте вкладку и не обновляйте страницу, иначе ответы могут быть потеряны. Таймер отображается на странице и запускается автоматически. Каждое задание оценивается в 1 балл; в вопросах с множественным выбором балл начисляется только при полном совпадении. Результат и оценка появляются автоматически после завершения.
