Ссылки по теме магистерской работы

Аннотированный перечень интернет-ресурсов по теме «Разработка системы бесконтактного управления интерфейсом с персонализацией жестовых команд».

1. Научные ресурсы и базы публикаций

  • 1. arXiv.org Крупнейший архив научных публикаций по компьютерным наукам, машинному обучению и компьютерному зрению.
  • 2. Google Scholar Поисковик научных публикаций. Позволяет находить статьи, цитирования, оценивать h-индекс авторов.
  • 3. ScienceDirect База научных публикаций Elsevier. Множество статей по HCI и жестовым интерфейсам.
  • 4. IEEE Xplore Цифровая библиотека IEEE. Ключевые публикации по техническим аспектам распознавания жестов.
  • 5. КиберЛенинка Русскоязычная научная библиотека открытого доступа.
  • 6. eLibrary.ru Российский индекс научного цитирования (РИНЦ).

2. Библиотеки и фреймворки компьютерного зрения

  • 7. OpenCV Открытая библиотека компьютерного зрения. Содержит готовые алгоритмы для детектирования лиц, рук, ключевых точек.
  • 8. PyTorch Фреймворк глубинного обучения от Meta. Основной инструмент для обучения нейросетей распознавания жестов.
  • 9. TensorFlow Платформа машинного обучения от Google. Содержит модули для работы с видео и жестами.
  • 10. Keras Высокоуровневый API для построения нейронных сетей. Удобен для быстрого прототипирования моделей.
  • 11. MediaPipe (Google) Набор ML-решений от Google. Включает готовые модули Hands (отслеживание рук), Face, Pose.
  • 12. OpenPose (CMU) Открытая библиотека для распознавания позы человека в реальном времени. Поддерживает отслеживание кистей рук.
  • 13. scikit-learn Классическая библиотека ML для Python. Полезна для классификации жестов на основе извлечённых признаков.

3. Аппаратные платформы для бесконтактного управления

  • 14. Ultraleap (Leap Motion) Производитель сенсоров для бесконтактного отслеживания рук. SDK позволяет разрабатывать жестовые интерфейсы.
  • 15. Microsoft Kinect SDK SDK для сенсора Kinect (RGB-D). Классический инструмент для отслеживания скелета человека и жестов.
  • 16. AirBending Приложение от компании Nanas Sound, которое превращает жесты рук в музыкальные команды. Оно использует камеру устройства (встроенную или внешнюю) и алгоритмы компьютерного зрения, чтобы в реальном времени отслеживать движения рук и транслировать их в MIDI-сигналы.

4. Публикации и обзоры по теме

  • 17. Булыгин Д.А., Мамонова Т.Е. Распознавание жестов рук в режиме реального времени Научная статья в «Вестнике НГТУ». Анализ существующих методов распознавания, предложена архитектура сверточной нейронной сети для классификации жестов.
  • 18. Распознавание языка жестов с помощью глубокого обучения Практическое руководство по полному циклу разработки: от подготовки данных до развёртывания модели на Streamlit. Точность 96%.
  • 19. Метод опорных векторов (SVM). Подходы, принцип работы и реализация с нуля на Python Подробный разбор метода опорных векторов с примерами кода. Полезно для понимания классических алгоритмов классификации жестов.
  • 20. Распознавание и перевод жестовых языков: обзор подходов Обзор современных подходов к распознаванию жестовых языков от SberDevices. Рассмотрены архитектуры TwoStream-SLT, S3D, mBART.
  • 21. Освоение OpenCV с помощью Python: полное руководство Подробное руководство по работе с OpenCV для обработки изображений и компьютерного зрения.
  • 22. Распознавание и перевод жестовых языков: обзор подходов (Хабр, hukenovs) Серия статей о распознавании русского жестового языка, датасете Slovo, участии в соревнованиях.

5. Датасеты для обучения моделей

  • 23. HaGRID (HAnd Gesture Recognition Image Dataset) — Kaggle Оригинальный датасет HaGRID: более 550 000 изображений, 18 классов жестов, 37 583 субъекта. Крупнейший открытый датасет статических жестов.
  • 24. hagrid-classification-512p-no-gesture-150k — Hugging Face Модифицированная версия HaGRID для задачи классификации изображений: 153 735 изображений, 19 классов (включая no_gesture).
  • 25. LeapGestRecog — Kaggle Датасет жестов рук, записанных с помощью Leap Motion. 10 классов жестов, изображения в градациях серого.
  • 26. Kaggle — датасеты по жестам Подборка открытых датасетов для обучения моделей распознавания жестов.
  • 27. Papers with Code — Gesture Recognition Свежие научные работы по распознаванию жестов с открытым кодом. Удобно сравнивать подходы и результаты.

6. Машинное обучение и нейросети (русскоязычные ресурсы)

  • 28. Как свёрточные нейронные сети видят мир Статья от преподавателя МГТУ им. Баумана о внутреннем устройстве CNN и компьютерного зрения.
  • 29. Модель ResNet — описание архитектуры Подробное описание архитектуры ResNet: остаточные блоки, варианты ResNet-18…152.
  • 30. Коротеев М.В. Основы машинного обучения на Python (учебник) Учебник для бакалавриата по машинному обучению: линейная регрессия, деревья решений, метод опорных векторов, нейронные сети.
